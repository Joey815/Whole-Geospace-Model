Issues found and fixed during this smoke:
  1. weimer_grid.dat is written as one formatted record containing both target
     latitude and longitude arrays. The first Fortran reader incorrectly
     assumed one value per read.
  2. The writer now uses the captured APEX POT export
     gcm%APEX%gcmOutput(hemi,1)%var, matching the HDF5 package source field.
  3. Kaiju/Fortran REMIX arrays are native (lon,lat), while the Python/HDF5
     view is (lat,lon). The writer now transposes to an internal (lat,lon)
     interpolation buffer before remapping to the SAMI3 Weimer grid.

Remaining limitations:
  - This is still a file-boundary payload writer, not direct Voltron -> SAMI3
    MPI transfer.
  - NORTH was validated. SOUTH is selectable through WACCMX_SAMI3_PHI_HEMI but
    still needs a separate smoke.
  - The shortened WACCMX_FILE smoke did not provide a clean natural exit before
    cancellation; add a one-shot writer/exit guard or a smaller dedicated
    writer unit smoke before treating this as a production run harness.
